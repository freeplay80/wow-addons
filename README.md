# wow-addons

월드 오브 워크래프트 포에버용 **퀘스트 도우미 0.7.0**입니다. 퀘스트 동선, 목표 표식, 방향과 거리를 표시합니다.

## 설치

1. 게임을 종료하고 GitHub에서 받은 ZIP의 압축을 풉니다.
2. 압축을 푼 폴더의 `ForeverQuestHelper`를 월드 오브 워크래프트의 `_forever_/Interface/AddOns`에 복사합니다. `AddOns/ForeverQuestHelper/ForeverQuestHelper_Forever.toc`가 있는지 확인하세요.
3. 게임을 실행하고 캐릭터 선택 화면의 애드온 목록에서 **퀘스트 도우미**를 활성화합니다. 게임에서 `/fqh`를 입력하면 도우미 창이 열립니다.

## 호드 추천 동선

호드 추천 동선과 미수락 퀘스트 지도 핀에는 [포에버용 QuestieDB](https://github.com/Questie/QuestieDB/releases/tag/v1.0.11)가 필요합니다. 호환되는 포에버용 `QuestieDB`가 이미 있다면 그대로 사용하고, 없다면 공식 ZIP에서 `QuestieDB` 폴더를 같은 `AddOns`에 설치한 뒤 활성화하세요. 모의 테스트에는 QuestieDB 1.0.11을 사용했습니다.

게임에서 호드 캐릭터로 `/fqh horde`를 입력하거나 `/fqh` 창의 **호드 추천 동선**을 누릅니다.

- **추천 동선**은 수락·수행·반납을 최대 30단계 제안합니다. **현재 지역 우선**은 현재 지역의 지점을 먼저 찾고, **전체 지역**은 지역 우선순위를 해제합니다. 다른 대륙·인스턴스 지점은 따로 표시합니다.
- **동선 추적**을 켜면 창을 닫아도 HUD에서 안내를 받습니다. 목록 클릭은 해당 퀘스트의 현재 가능한 단계를 HUD에 고정하고, Shift+클릭은 기본 지도 핀을 설정합니다. 우클릭은 상세를 엽니다. **건너뛰기**로 이번 접속 중 해당 퀘스트를 추천에서 제외하고, **제외 해제**로 되돌릴 수 있습니다.
- 공동 반납을 추천할 때 HUD에 예상 절약 거리, 퀘스트와 반납 NPC 또는 물체가 표시됩니다. 동선을 재계산해도 남은 항목이 유지되며, 반납한 퀘스트부터 목록에서 빠집니다.
- **퀘스트 목록**에서 완료·진행 중·미시작 상태를 볼 수 있습니다. 이름 또는 ID를 검색하면 연계, 수락 조건, 수락·수행·반납 위치를 확인할 수 있습니다. 인스턴스 입구와 아이템 획득 후보를 별도로 표시합니다.
- 호드 캐릭터의 월드맵에서 지역을 열면 수락 조건을 충족한 미수락 퀘스트의 시작 장소가 청록색 `!`로 보입니다. 핀에 마우스를 올리면 퀘스트와 시작 대상을 확인할 수 있습니다. `/fqh`의 **호드 미수락 퀘스트 지도 핀**에서 끌 수 있습니다.
- QuestieDB가 없거나 호환되지 않으면 호드 동선 창과 월드맵에 확인할 사항이 표시됩니다.
- 거리 계산은 지도 좌표를 기준으로 합니다. 도로, 비행 경로, 배, 귀환석 이용 시간은 포함하지 않습니다. 퀘스트 진행이나 조건이 바뀌면 목록을 다시 계산합니다.
- QuestieDB에서 누락된 포에버 신규 퀘스트와 일부 서버 전용 조건은 확인이 필요합니다. DB 수락 조건을 충족한 퀘스트도 실제 수락 가능 여부는 게임에서 확인하세요.
- Wowhead 포에버에서 반납 NPC와 대화·전달만 하면 되는 퀘스트 3개를 개별 확인했습니다. [할 일 찾기](https://www.wowhead.com/forever/quest=4641/your-place-in-the-world), [사르코스 후속](https://www.wowhead.com/forever/de/quest=804/sarkoth), [일꾼의 짐](https://www.wowhead.com/forever/quest=2161/a-peons-burden)

건물이나 던전에서 게임이 현재 층과 목적지 층을 같은 지도 그룹으로 제공하면 화면 길 안내와 동선 목록에 **위층으로** 또는 **아래층으로**를 표시합니다. 일반 지도 좌표만 있는 언덕이나 동굴은 방향과 거리로 안내합니다.

## 검증 범위

0.7.0의 동선, HUD와 지도 로직은 Lua 모의 환경에서 확인했습니다. 이번 버전의 실제 포에버 게임 화면과 조작은 미검증입니다.
