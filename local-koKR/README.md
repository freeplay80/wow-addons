# 한국어 번역 작업 보관

이 폴더는 게임의 AddOns 폴더와 분리된 번역 원본·수정본 보관 위치입니다. 번역 파일만이 아니라 수정 전 원본과 당시 검사 결과도 함께 Git에 기록합니다.

| 경로 | 내용 |
| --- | --- |
| `Lueur/`, `ForeverLootSparkles/`, `HanharEnhancementHUD/` | 첫 한국어 번역을 적용한 파일 |
| `original/` | 첫 번역 전 설치 파일 |
| `Hanhar-ui.txt`, `build-hanhar.cjs` | Hanhar 표시 문구와 첫 적용용 생성 스크립트 |
| `additional-2026-11-08/` | KeepOrSell 등 추가 번역의 원본·수정본·문구·검증 및 적용 자료 |
| `font-fix-2026-11-08/` | KeepOrSell 제목과 소개 문구의 한글 글꼴 수정 전후 파일 |

`source/`는 각 작업 당시의 수정본이며, `original/`은 해당 수정 직전의 백업입니다. 폴더별 시점이 다르므로 최신 파일을 복구할 때는 뒤에 한 수정도 함께 확인해야 합니다. 현재 게임 설치본의 통합 사본은 저장소 루트의 `AddOns/`에 있습니다.

적용 스크립트는 당시 버전과 해시가 일치하는 파일에 한정됩니다. 업데이트된 애드온에 자동으로 다시 적용하는 도구가 아니며, 일부 스크립트는 이미 백업이 있거나 해시가 달라지면 중단합니다. 새 버전에는 원문과 수정본을 비교해 번역을 병합하고 Lua·로드 순서·서식을 확인한 뒤 게임 폴더에 복사하세요.

검증 스크립트는 프로젝트의 `tests/quest-route/node_modules/fengari`를 사용하는 로컬 검사 자료입니다. 의존성 폴더와 테스트 환경은 이 백업에 포함하지 않습니다. 모의 검증 통과와 실제 게임 화면 확인은 구분하며, 당시 확인하지 못한 화면·줄바꿈은 NOT_TESTED입니다.
